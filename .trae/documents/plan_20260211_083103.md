# 问题分析

通过分析代码，我发现所有导出为空白的问题可能由以下几个原因导致：

1. **容器高度问题**：创建的导出容器没有设置高度，导致内容无法正确渲染
2. **渲染时间不足**：容器添加到body后没有足够的时间渲染就立即生成图片
3. **浏览器优化**：由于容器位置在屏幕外（left: -9999px），可能被浏览器渲染优化跳过
4. **样式继承问题**：复制的内容可能缺少必要的样式继承

# 解决方案

我将修改两个导出函数，解决这些问题：

1. **修改图片导出函数**：
   - 设置容器的高度为原始元素的高度
   - 添加额外的等待时间，确保容器完全渲染
   - 优化容器的样式设置

2. **修改PDF导出函数**：
   - 同样设置容器的高度
   - 添加额外的等待时间
   - 优化容器的样式设置

3. **确保容器渲染**：
   - 在容器添加到body后，等待DOM更新和渲染
   - 使用setTimeout确保有足够的渲染时间

# 预期效果

修改后，两个导出函数将能够正确渲染容器内容，从而解决导出为空白的问题。无论是第一次导出还是后续导出，无论是导出图片还是PDF，都能成功导出完整的行程计划。
